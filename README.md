# 裏雄J会 成績表

ゴルフ会「裏雄J会」の成績・HC・賞金をスマホで見て、幹事が入力できるWebアプリ。
大会ごとにスコアを入れると、順位・賞金・次回HC・年間スコアボード・HC推移・賞金表・翌年HCが自動で出る。

公開URL: https://shar19-ops.github.io/urayu-jkai/

## ファイル
- `index.html` 画面と見た目（アイコンは data URI で埋め込み）
- `app.js` 画面の動き・保存（Firebase Realtime Database の REST。未接続なら端末内の localStorage）
- `core.js` 計算ロジック（画面に依存しない純粋関数）
- `tests/core.test.js` 計算のテスト（`npm test` または `node --test tests/core.test.js`）

## 使い方
- 閲覧は誰でも。入力は右上「幹事」からログインした幹事のみ（パスワードは `app.js` の `ADMIN_PASSWORD`）。
- 共有：⚙️設定 →「データの共有」に Firebase Realtime Database の URL を入れて接続する。データは `uraj/years/<年>` に入る。
  メンバーには「メンバー用リンクをコピー」（`?db=` 付きのURL）を配る。
- 年度末：⚙️設定 →「翌年度をつくる」で、来年HC・昨年平均・生涯獲得額を引き継いだ新年度を作る。

## 注意
- このリポジトリは公開されている。メンバーの実名入りデータ（バックアップJSON）や Firebase の URL はコミットしない。
- 幹事パスワードは画面上のチェックだけで、データを守る仕組みではない。書き込みの制限は Firebase のルールで行う。

## 計算ルール
- 順位は NET 順。NET が同じなら GROSS の良い方が上。
- 賞金：参加費（1,000円）の合計を、優勝＝合計−準優勝、準優勝＝5人以下1,000円／6〜10人2,000円／11人以上3,000円で分ける。
- 次回HC：優勝は2割・準優勝は1割カット（参加4人未満はカット無し）。NET が72を切ったら、そのアンダー分を HC から引いてからカット。
- 翌年HC：（年間平均−72）×0.8、上限36。不参加回はベストスコアを入れて平均。年間賞金王は1割カット。幹事が手で直すこともできる。
